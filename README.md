# Organisation des dossiers

Le dossier source est organisé de la façon suivante :

- assets : contient les images vectorielles tel que les flèches ou les étoiles
- components : contient les composants utilisés avec leur fichier scss
- hooks : contient les hooks personnalisés
- pages : contient les différentes pages du site web
- routes : contient le composant utilisé pour la gestion du routage
- styles : contient le fichier de mise en page principale, les mixins et les variables
